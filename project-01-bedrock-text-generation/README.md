# Project 01 - Bedrock Text Generation

## Overview
This project explores using **Amazon Bedrock** to invoke foundation models for text generation tasks.

## Goals
- Learn how to interact with Amazon Bedrock's API to invoke foundation models (e.g., Anthropic Claude, Amazon Titan)
- Understand prompt engineering techniques relevant to the AWS Generative AI Developer - Professional exam
- Build a simple application that sends prompts and receives generated text responses

## AWS Services Used
- Amazon Bedrock
- AWS IAM (for permissions)

## Key Concepts
- Foundation Models (FMs)
- Prompt engineering
- Inference parameters (temperature, top-p, max tokens)
