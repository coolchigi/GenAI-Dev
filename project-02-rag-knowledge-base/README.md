# Project 02 - RAG Knowledge Base

## Overview
This project implements a **Retrieval-Augmented Generation (RAG)** pipeline using Amazon Bedrock Knowledge Bases to ground LLM responses in custom data.

## Goals
- Learn how to create and configure an Amazon Bedrock Knowledge Base
- Understand how RAG reduces hallucinations by grounding responses with retrieved context
- Build an application that queries a knowledge base and generates accurate, cited responses

## AWS Services Used
- Amazon Bedrock Knowledge Bases
- Amazon S3 (for storing source documents)
- Amazon OpenSearch Serverless (vector store)
- AWS IAM (for permissions)

## Key Concepts
- Retrieval-Augmented Generation (RAG)
- Vector embeddings and semantic search
- Chunking strategies for documents
- Knowledge base sync and ingestion
